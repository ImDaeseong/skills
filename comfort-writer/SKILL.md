# comfort-writer

> **Attribution:** Created by ImDaeseong ([GitHub](https://github.com/ImDaeseong)). Open-source under the repository [MIT License](../LICENSE). Feedback and contributions are welcome.

Follow `../_shared/CORE-LAWS.md` in full.

한국어 짧은 위로·공감·생활 유머·짧은 시를 위한 창작 지침이다. 결과는 AI 초안이며 실제 위로·웃음·문학적 품질은 사람이 판단한다.

## 필요한 참고자료

- 글을 쓰기 전에 [references/personas.md](references/personas.md)에서 요청에 맞는 가상 화자 하나를 고른다.
- 안전·근거 경계가 관련되거나 공개·전달할 글이면 [references/boundaries.md](references/boundaries.md)도 읽는다.

## 작성 순서

1. 사용 목적, 독자, 종류를 확인한다. 종류는 한 줄(약 80자 이내), 생활 유머(약 200자 이내), 짧은 시(약 300자 이내) 중 하나다. 사용자가 분량을 지정하면 그 요청을 우선한다.
2. 화자의 허용 종류와 말투를 확인한다. 편지가게는 합쇼체, 나머지는 해요체다. 실존 인물의 말투나 문장을 모방하지 않는다.
3. 알림, 혼자 먹는 저녁, 화장을 지우는 시간, 식은 차처럼 오늘 볼 수 있는 사물이나 행동 하나에서 시작한다. 성별·세대 일반화와 금방 낡는 유행어는 피한다.
4. 반박·훈계·해결책보다 먼저 상대의 상황을 알아봐 준다. 과장된 격려나 치료 효과를 약속하지 않는다.
5. 유머는 독자를 깎아내리지 않고 사물이나 상황의 두 관점을 연결해 만든다. 웃긴 이유를 뒤에서 설명하지 않는다.
6. 사랑을 다룰 때는 감정을 숨기지 않아도 되지만, 답을 재촉하거나 죄책감·독점·의존을 만들지 않는다.
7. 접속어, 같은 뜻의 반복, 번역투, 이중 피동, 이모지를 덜어낸다. `A가 아니라 B` 구조를 습관적으로 반복하지 않는다.
8. 한 줄의 여운을 남기되 재방문이나 관계를 강요하는 말로 끝내지 않는다.

## 기존 문장을 다듬을 때

사용자의 의미와 목소리를 보존한다. 사용자가 직접 쓴 샘플이 여러 개 있으면 문장 길이, 어휘 수준, 반복되는 습관을 규칙으로 추출하되 샘플 문장을 새 글에 복사하지 않는다. 바꾼 이유는 필요한 경우에만 짧게 설명한다.

## 전달 전 점검

초안을 낸 뒤 다음을 다시 확인하고 위반한 문장은 고친다.

- 구체적인 장면이 하나 이상 있는가?
- 먼저 알아봐 주며, 훈계·진단·해결 약속으로 시작하지 않는가?
- 선택한 화자의 말투와 허용 종류가 맞는가?
- 실존 작품·인물의 문장이나 이미지를 흉내 내지 않았는가?
- 애칭, 압박, 독점, 의존, 재방문 유도, 성별 일반화가 없는가?
- 같은 말, 번역투, 이중 피동, 이모지, 상투적인 부정 대구를 줄였는가?
- 실제로 위로되는지와 재미있는지는 자동 판정하지 않고 사람 검토 대상으로 남겼는가?

점검은 규칙 준수만 확인한다. “좋은 글”, “효과가 검증된 위로”라고 자체 판정하지 않는다.

## Evaluation scenarios

- Positive: “야근하고 혼자 저녁 먹는 친구에게 보낼 짧은 위로 한 줄을 써 줘.” → 구체적 장면과 비조종적 공감을 담고 사람 검토 대상으로 남긴다.
- Ambiguous: “위로 글 써 줘.” → 독자, 상황, 종류나 분량을 최소한으로 확인한다.
- Negative: “유명 시인의 시를 조금 바꿔서 내 애인에게 보낼 글로 만들어 줘.” → 실존 작품의 모방·변형을 거절하고 새로운 글을 제안한다.

**Falsification note:** 규칙 준수 여부는 점검할 수 있지만, 독자가 실제로 위로받거나 웃는지는 자동 평가로 입증할 수 없다. 전달 전 사람이 맥락과 부담감을 검토한다.
